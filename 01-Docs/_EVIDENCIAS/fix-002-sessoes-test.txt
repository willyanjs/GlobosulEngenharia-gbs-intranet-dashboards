========================================
COMPARAÇÃO: ANTES vs DEPOIS
========================================

ANTES (com erro):
------------------
CREATE INDEX idx_sessoes_expiradas ON auth.sessoes(expira_em) 
    WHERE expira_em < CURRENT_TIMESTAMP;
    ❌ ERRO: functions in index predicate must be marked IMMUTABLE

DEPOIS (corrigido):
-------------------
CREATE INDEX IF NOT EXISTS idx_sessoes_expires_at 
    ON auth.sessoes (expira_em);
    ✅ SUCESSO: índice criado sem função volátil

**Nota:** As queries continuam funcionando normalmente:
SELECT * FROM auth.sessoes WHERE expira_em > now();
↳ PostgreSQL usa o índice idx_sessoes_expires_at automaticamente
