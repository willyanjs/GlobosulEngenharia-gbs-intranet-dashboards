🐛 TROUBLESHOOTING
=====================================================

Erro: "DO 836" ou syntax error
→ Executar: dos2unix migrations/004_audit_core.sql

Erro: "relation already exists"
→ OK! Migration é idempotente, só ignora

Erro: "index already exists"
→ OK! IF NOT EXISTS torna warning apenas

Erro: "trigger already exists"
→ Verificar se migration 001 foi aplicada (bloco idempotente)

Erro: "permission denied"
→ Verificar OWNER TO gbs_dev nas funções/tabelas

Erro: "could not find function"
→ Aplicar migrations em ordem (000 → 016)
